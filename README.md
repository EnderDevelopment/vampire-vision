# Vampire Vision Minecraft Texture

Vampire Vision is a Minecraft texture resource pack asset for a blood health overlay. It provides a full screen SVG overlay with dark red shading, blood edged patterns, and bright red highlights for use in a Minecraft addon or health based visual effect system.

## Install

1. Create or open a Minecraft resource pack.
2. Place `assets/gui/blood_health_overlay.svg` in the pack at the same path.
3. If your overlay system requires PNG files, convert the SVG to PNG before adding it to the resource pack.
4. Add the converted overlay to the texture or UI configuration used by your health effect system.
5. Enable the resource pack in Minecraft.

## Use

1. Reference the overlay asset from your addon or compatible UI system.
2. Display it with increasing opacity as the player's health decreases.
3. Set the overlay to full opacity when the player has 1 heart.
4. Adjust the opacity thresholds in the health effect system to control when the blood effect appears.

The included file is the visual overlay artwork. Health detection, opacity changes, and addon configuration must be provided by the system that displays the texture.
